# Jeevan Sathi AI ✨

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE)

**Explore, Experience, and Evaluate the Future of On-Device Generative AI with Jeevan Sathi AI.**

Engineered with pride in Sitamarhi, Bihar by Aayush. Jeevan Sathi AI is an advanced, independent platform for running powerful open-source Large Language Models (LLMs) directly on your mobile device. Experience high-performance Generative AI—fully offline, private, and lightning-fast.

**Powered by Advanced On-Device Models**
This application brings support for cutting-edge open-source models, including the Gemma 4 family. Experience advanced reasoning, logic, and creative capabilities without ever sending your data to a cloud server.

## ✨ Core Features

* **Agent Skills**: Transform your LLM from a conversationalist into a proactive assistant. Use the Agent Skills tile to augment model capabilities with tools like Wikipedia for fact-grounding, interactive maps, and rich visual summary cards[span_3](start_span)[span_3](end_span).
* **AI Chat with Thinking Mode**: Engage in fluid, multi-turn conversations and toggle the Thinking Mode to see the model’s step-by-step reasoning process[span_4](start_span)[span_4](end_span).
* **Ask Image**: Use multimodal power to identify objects, solve visual puzzles, or get detailed descriptions using your device’s camera or photo gallery[span_5](start_span)[span_5](end_span).
* **Audio Scribe**: Transcribe and translate voice recordings into text in real-time using high-efficiency on-device language models[span_6](start_span)[span_6](end_span).
* **Prompt Lab**: A dedicated workspace to test different prompts and single-turn use cases with granular control over model parameters like temperature and top-k[span_7](start_span)[span_7](end_span).
* **Mobile Actions & Tiny Garden**: Unlock offline device controls and explore experimental mini-games powered by specialized natural language models[span_8](start_span)[span_8](end_span).
* **100% On-Device Privacy**: All model inferences happen directly on your device hardware. No internet is required, ensuring total privacy for your prompts, images, and sensitive data[span_9](start_span)[span_9](end_span).
